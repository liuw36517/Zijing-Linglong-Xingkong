# 🌌 紫荆玲珑星空

> 一个基于 Three.js 开发的沉浸式 3D 太空探索静态网页。

探索浩瀚宇宙，穿越星河，发现属于你的星空世界。


## ✨ 项目介绍

《紫荆玲珑星空》是一款纯前端 WebGL 星空展示项目。

无需服务器，无需数据库，可直接部署到 GitHub Pages。

项目通过 Three.js 构建：

- 🌍 3D幻想星球
- 🛰 环绕卫星系统
- ☄ 陨石飞行轨迹
- 🚀 空间站场景
- 🌌 银河星空背景
- 🔭 自由视角探索


## 🌠 功能特点

### 🌍 行星系统

- 真实3D球体渲染
- 星球自转动画
- 大气光环效果
- 科幻紫色星球主题


### 🛰 卫星系统

包含：

- 多颗环绕卫星
- 自动轨道运动
- 太空运行效果


### ☄ 陨石系统

实现：

- 随机陨石生成
- 飞行轨迹
- 火焰尾迹效果
- 陨石带模拟


### 🛰 空间站

包含：

- 环形空间站
- 太阳能板结构
- 自动旋转展示


## 🎮 操作方式


### PC端

鼠标：

- 左键拖动：旋转视角
- 滚轮：缩放距离


### 移动端

支持：

- 手指拖动旋转
- 双指缩放


## 🛠 技术栈


| 技术 | 用途 |
|-|-|
| HTML5 | 页面结构 |
| CSS3 | UI设计 |
| JavaScript | 逻辑控制 |
| Three.js | 3D渲染 |
